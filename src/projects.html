Firebase Backend

1. Beginner — Firebase Basics

What is Firebase? (BaaS concept)

Firebase is a Backend-as-a-Service (BaaS) by Google. Instead of building your own server, database, and auth system, Firebase gives you ready-made services that talk directly to your frontend via SDK. No Express, no MongoDB setup — just SDK calls.

Create a Firebase project & get config keys

Go to console.firebase.google.com → Add project → Register a web app → Copy the firebaseConfig object (apiKey, authDomain, projectId, etc.). These keys are safe to expose in the frontend.

Install & initialize Firebase SDK in the project 
npm install firebase

// src/firebase.js
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";
import { getFirestore } from "firebase/firestore";
import { getStorage } from "firebase/storage";

const firebaseConfig = { /* your keys */ };
const app = initializeApp(firebaseConfig);

export const auth = getAuth(app);
export const db = getFirestore(app);
export const storage = getStorage(app);
Firebase console walkthrough

Learn the dashboard: Authentication tab, Firestore Data tab, Storage tab, Hosting tab, and Rules tab. You will use all five throughout this project.

2. Intermediate — Auth & Database

Firebase Auth — email/password signup & login 
import { createUserWithEmailAndPassword,
         signInWithEmailAndPassword } from "firebase/auth";

await createUserWithEmailAndPassword(auth, email, password);
await signInWithEmailAndPassword(auth, email, password);
Google Sign-In with popup 
import { signInWithPopup, GoogleAuthProvider } from "firebase/auth";

const provider = new GoogleAuthProvider();
await signInWithPopup(auth, provider);
Auth state listener — keep user logged in across refresh 
import { onAuthStateChanged } from "firebase/auth";

onAuthStateChanged(auth, (user) => {
  if (user) setCurrentUser(user);   // logged in
  else setCurrentUser(null);        // logged out
});
Protected routes with React Router

Wrap private routes in a <ProtectedRoute /> component that checks currentUser. If null → redirect to /login.

Firestore CRUD — create, read, update, delete a job 
import { collection, addDoc, getDocs,
         doc, updateDoc, deleteDoc } from "firebase/firestore";

// Create
await addDoc(collection(db, "jobs"), { title, company, location });

// Read
const snap = await getDocs(collection(db, "jobs"));
const jobs = snap.docs.map(d => ({ id: d.id, ...d.data() }));

// Update
await updateDoc(doc(db, "jobs", id), { saved: true });

// Delete
await deleteDoc(doc(db, "jobs", id));
Real-time updates with onSnapshot 
import { onSnapshot, collection } from "firebase/firestore";

const unsub = onSnapshot(collection(db, "jobs"), (snap) => {
  setJobs(snap.docs.map(d => ({ id: d.id, ...d.data() })));
});
// cleanup: unsub();
Firestore data modeling — jobs, savedJobs, appliedJobs, users 
users/{uid}
  ├─ name, email, photoURL, resumeURL, createdAt

jobs/{jobId}
  ├─ title, company, location, salary, type, tags[]

users/{uid}/savedJobs/{jobId}
  ├─ savedAt

users/{uid}/appliedJobs/{jobId}
  ├─ appliedAt, status

3. Advanced — Real Backend Setup

Security Rules — only owner can read/write their data 
// Firestore rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /jobs/{jobId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
Storage rules — protect uploads 
service firebase.storage {
  match /b/{bucket}/o {
    match /resumes/{uid}/{file} {
      allow read, write: if request.auth.uid == uid;
    }
  }
}
Composite indexes — for multi-filter + sort queries 
import { query, where, orderBy, limit,
         startAfter, getDocs } from "firebase/firestore";

const q = query(
  collection(db, "jobs"),
  where("location", "==", city),
  where("type", "==", "full-time"),
  orderBy("postedAt", "desc"),
  limit(10)
);

Firebase will throw a link in console to create the composite index automatically. Click it and wait 1–2 min.

Pagination + Infinite scroll with startAfter 
let lastDoc = null;

async function loadMore() {
  const q = query(
    collection(db, "jobs"),
    orderBy("postedAt", "desc"),
    startAfter(lastDoc),
    limit(10)
  );
  const snap = await getDocs(q);
  lastDoc = snap.docs[snap.docs.length - 1];
  setJobs(prev => [...prev, ...snap.docs.map(d => d.data())]);
}
